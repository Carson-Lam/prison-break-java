# Prison Break

## Overview

Prison Break - a retro atari-breakout inspired java app. 

## Features

- Levelling system:
  - Scaling difficulty
  - cutscenes
- High Score logging and reset capabilities
- Full sprite updates

## Dependencies

- This is a Java App

- packages include: <br>

  1. [Swing](https://docs.oracle.com/en/java/javase/11/docs/api/java.desktop/javax/swing/package-summary.html)
  2. [awt](https://docs.oracle.com/en/java/javase/11/docs/api/java.desktop/java/awt/package-summary.html)
  3. [util](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/package-summary.html)

- Fonts from [DaFont](https://www.dafont.com/vcr-osd-mono.font)
